Welcome

This app exercises every feature the Crystal Webview framework offers. Use the tabs above to explore each one. Live data streams from the backend — the clock and memory pill update every second without polling.

Try this

  1. Open Files, pick a file. It appears in Recents.
  2. Open WebSocket, connect to the echo server.
  3. Click Trigger notification below.
